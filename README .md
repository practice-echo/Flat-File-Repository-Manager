【重要规则】
  - 所有文件平铺在 D:\\ROOT 根下，禁止建子文件夹
  - 物理位置 = ROOT 路径 + 文件名
  - 一个文件可以属于多个 Flow（多归属），复制记录即可
  - 导出仅复制，不影响仓库；删除可单独选择是否物理删除
  - 成套工具建议打包为 ZIP 入库，避免散文件依赖问题
  - 建议每到新盘执行“1”



### 环境要求

- Windows 10/11
- [Docker Desktop](https://www.docker.com/products/docker-desktop/)（必须安装并启动）

### 首次使用

1. 下载 `资源仓库管理工具.exe`
2. 将 EXE 复制到你想要作为资源仓库的盘符（如 D 盘）    注：第一次初始化盘为数据库存储盘，切换数据库请在对应盘符下执行exe
3. 确保 Docker Desktop 已启动
4. 双击运行 EXE
5. 选择菜单 `1. 初始化数据库`
6. 等待容器创建和数据库初始化完成
7. 选择菜单 `3. 扫描 ROOT 并入库 point` 开始管理你的资源

### 核心功能说明

#### 1. 初始化数据库

- 自动检查并启动 MySQL Docker 容器
- 创建当前盘符对应的独立数据库
- 初始化表结构和根节点
- 创建 `盘符:\ROOT` 和 `盘符:\ROOT\MYSQL_DB` 目录

#### 2. 显示 Flow 树

以树形结构展示所有虚拟目录（Flow）及其包含的文件数量，有文件的目录会以绿色显示。

#### 3. 扫描 ROOT 并入库 point

- 递归扫描 `盘符:\ROOT` 目录下的所有文件
- 自动计算文件哈希、提取文件信息
- 自动去重（相同哈希的文件只入库一次）
- 自动跳过 `MYSQL_DB` 目录

#### 4. 创建 Flow

交互式创建虚拟目录，支持无限层级嵌套。

#### 5/6. 列出 Flow 下 point

列出指定 Flow 下的文件，支持递归列出所有子 Flow 的文件。

#### 7. 复制 point 至其他 Flow

将文件从一个虚拟目录复制到另一个虚拟目录（仅复制数据库记录，不复制物理文件）。

#### 8. 整理与清理

- 清理数据库中不存在的物理文件记录
- 查找重复文件

#### 9. 批量导入旧文件夹

将现有文件夹结构批量导入为 Flow 结构，保留原有的目录层级。

#### 10. 备份与恢复数据库

- 备份当前盘符的数据库
- 备份所有盘符的数据库
- 从备份文件恢复数据库
